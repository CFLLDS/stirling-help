# What the assistant saved

**Page: Finance, What the assistant saved**

Besides answering the phone, the assistant does routine checking in the background, such as clearing timesheet items that match the roster and ranking the exceptions that need a person. This section estimates what that is worth.

| Tile | Meaning |
|---|---|
| **Estimated SG&A avoided** | The value of admin time avoided in the period, and what that would be in a month at the same rate |
| **Time saved** | Hours saved, and how much of it was coordinator time |
| **Decisions surfaced** | Items the assistant put in front of a person, so that nobody had to go looking |
| **Timesheet items auto-cleared** | Items that matched and needed no human check, with the number of exceptions ranked for review |

The line underneath names the biggest driver, for example payroll reconciliation.

## How far to trust it

The **events** are measured: each one is something the assistant actually did. The **time and cost** are estimated by pricing each kind of event with the published cost assumptions. The page states this, gives the date of the assumptions, and gives a confidence level.

This is a saving, not an invoice, and not cash. It is staff time released for other work.

## Why this differs from the Telephony page

Telephony shows the time avoided by answering calls and messages, for the current month. This section covers background admin work, for the reporting period. They measure different things and are not meant to match.
