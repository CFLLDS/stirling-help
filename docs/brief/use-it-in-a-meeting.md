# Use the Brief in a meeting

The Brief is designed to be put on a screen at the start of a management or trustee meeting.

## Before the meeting

1. Open the **Brief**.
2. Set the [reporting period](../getting-started/reporting-period.md). Use **Last 28 days** for a monthly meeting and **This quarter** for a board.
3. Read the summary, then run your eye down the figures. Note anything that surprises you.
4. For each surprise, open the tab that holds the detail and read the sentence under the figure. Most surprises are explained there.
5. Check **Call-backs waiting** and **Safeguarding raised**. If either is not zero, make sure somebody already owns it. These should not wait for a meeting.

## In the meeting

- Start from the last line of the summary: where attention is most needed.
- Keep to one decision. The page is built for that.
- When someone asks "where does that number come from?", open the matching tab. Every figure on the Brief appears on another tab with its source.

## After the meeting

Copy the web address into the minutes. It holds the tab and the period, so anyone with access can open the same view later. The figures for a past period do not change, except where a late record arrives in a source system.

!!! note "Quoting the summary"
    If you want to quote the written summary in a paper, check each number in it against the figures first, and say that it was generated from them.
