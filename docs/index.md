# Stirling Help Centre

Stirling brings your services, phones, buildings and money onto one set of pages, so that a chief executive, a manager or a trustee can see what is happening and decide what to do about it.

You do not enter anything into Stirling. It reads from the systems you already use and shows you the result. These guides explain what each page shows, where the figures come from, and how to use them.
