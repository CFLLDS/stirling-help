# Read a heat grid

Several pages use the same picture: a grid with a **row for each day** and a **column for each hour**, midnight to midnight. You will find it for home support visits, footcare appointments, handyperson bookings, calls, and calls answered by the assistant.

## How to read it

| You see | It means |
|---|---|
| A darker square | More happened in that hour |
| A paler square | Less happened |
| A square marked as **no reading** | Nothing arrived for that hour. This is not the same as zero |

The key under the grid runs from **less** to **more**.

Under each grid is a sentence that tells you the busiest day and hour, how many that was, and how many squares have no reading. The same information is there for people using a screen reader.

## What to look for

- **A dark column.** The same hour is busy every day. That is where you need people.
- **A dark row.** One day was unusually busy. Look at what happened that day.
- **Pale squares in opening hours.** Capacity you are paying for and not using.
- **Two grids together.** On the Telephony page, the call grid and the assistant grid have the same layout so you can compare them. Where the first is dark and the second is pale, people rang and a person answered. Where both are dark, the assistant was needed.

## Grids that look forward

The footcare grid carries on past today, because it shows appointments already booked. The right-hand half shows you how full the coming weeks are, while there is still time to fill them.
